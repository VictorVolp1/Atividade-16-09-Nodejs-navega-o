## Objetivo
Desenvolver uma aplicação web de gestão para categorias, clientes, fornecedores e produtos, com interface moderna, responsiva e funcional, preservando a estrutura e as rotas do projeto original.

## Tecnologias Utilizadas
- Node.js
- Express
- EJS
- Bootstrap 
- HTML
- CSS
- JavaScript

## Funcionalidades
- Cadastro de categorias, clientes, fornecedores e produtos
- Listagem de categorias, clientes, fornecedores e produtos 
- Edição de categorias, clientes, fornecedores e produtos
- Exclusão de categorias, clientes, fornecedores e produtos
- Navegação por módulos
- Interface responsiva para desktop, tablet e celular

## Prompt Utilizado
"Analise as páginas e modernize a interface do meu sistema de categorias, clientes, fornecedores e produtos. Crie um layout mais moderno, profissional e responsivo, com melhor organização dos elementos, cores harmoniosas, tipografia agradável, cartões modernos, tabelas organizadas e botões aprimorados. Melhore a navegação, os formulários de cadastro e edição, os ícones e os efeitos visuais. Utilize uma paleta de cores consistente, com verde como cor principal, e garanta uma boa experiência em computadores, tablets e celulares. Preserve as funcionalidades existentes, as rotas e a estrutura do projeto. Mantenha a compatibilidade. Modifique os arquivos necessários, reutilize componentes e garanta que todas as operações de cadastro, consulta, edição e exclusão continuem funcionando corretamente."

## Uso da Inteligência Artificial
A inteligência artificial foi utilizada para apoiar a reformulação visual do sistema, sugerindo organização de layout, paleta de cores, estrutura de componentes, refinamento da navegação e modernização dos formulários e tabelas, mantendo a compatibilidade com a aplicação existente.

## Alterações Sugeridas pela IA
- Reestilização completa da interface
- Uso de paleta verde como identidade visual principal
- Modernização de navbars, cards e botões
- Organização de tabelas com melhor hierarquia visual
- Ajuste em formulários para maior legibilidade e usabilidade
- Melhoria na responsividade e no espaçamento
- Destaque da página ativa no menu
- Inserção de ícones para melhorar a experiência visual

## Alterações Implementadas pelo Grupo
- Aplicação do novo layout visual em todas as páginas
- Ajuste da navegação para destacar a seção ativa
- Modernização dos formulários de cadastro e edição
- Atualização das telas de listagem com tabelas mais estruturadas
- Reformulação do layout inicial com dashboard visual
- Mantém a lógica de rotas e da funcionalidade original do sistema
- Validação do funcionamento das operações de cadastro, edição e exclusão
